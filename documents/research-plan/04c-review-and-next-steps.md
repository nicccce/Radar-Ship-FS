# 4C NO-GO 后的科研判断与下一步

日期：2026-09-17。本文是对现有产物的后续解读，不修改 4C 的冻结协议、门槛、结果或 audit。

## 核对结果

直接读取 `experiments/k32_reward_robustness_v1/analysis/fold_results.csv` 重算，forward→swap 的五折平均增益为 **+0.100853 pp**，正/平/负为 **3/2/0**，与 `final-decision.json` 完全一致。两项门槛分别是平均至少 +0.2 pp、至少 4/5 为正，因此 NO-GO 正确。

`audit.json` 为 passed，成本与结构门槛为 true。`verification.json` 记录 4C 交付时全量 178 executed / 178 passed / 0 collection errors。此前 11 个 collection errors 已由 4C-0 修复；不是本次 NO-GO 的原因。本次只重算保存的汇总并核对已保存的审计，没有重新运行 pytest、训练或搜索。

## 结果意味着什么

1. **当前“强 forward 起点 + 此 LR 评分器 + 最多两轮 swap”没有显示足够稳定且足够大的外层收益，按约定停止扩大静态 RL。** 4D、5A、5B 和这一 K=32 分支的任务 6 均不准入；未执行不能伪装成算法 NO-GO 报告。
2. **这不是 RL 无效的证明。** 4C 没有 PPO/DQN 训练；两轮单交换也不覆盖整个子集空间。它是继续投入的前置门槛失败。
3. **也不能断言评分器完全失效。** 本轮没有负向 fold，三折有正增益；两折是在训练内部完整第一轮邻域无严格改善后停止，因而 endpoint 就是原起点。可保留“局部收益小且随 context 变化”的描述。
4. 4B 的 +0.4149 pp 与 4C 的 +0.1009 pp 来自不同 outer partition 和训练规模，不能把两者的差直接归因于某一个软件错误、scorer 退化或单一机制。原 4B 整体仍是 NO-GO。
5. 不把门槛从 +0.2 pp 改到 +0.1 pp，不删去持平 folds，不增加 split/K/reward 扫描。否则只是重复利用开发数据寻找过关结果。

## 值得保留的静态结果

同一 4C outer partition 下，五折平均 LR BAcc 为：

| 方法 | 特征数 | LR BAcc |
|:---|---:|---:|
| All Features | 65 | 91.8579% |
| MI-32 | 32 | 91.5176% |
| LR-forward | 32 | 91.5743% |
| LR-forward + swap≤2 | 32 | 91.6751% |

32 维相对 65 维减少 **50.77% 的特征数量**，LR-forward+swap 相对全特征平均低 **0.1828 pp**。不过 fold 2 的配对差为 **-1.8350 pp**；平均接近不能掩盖跨 fold 差异，也不能证明非劣或性能等价。这些 folds 已参与研究决策，没有独立测试性质。

因此，“压缩”可以是新的问题假设，但目前不是已实现的科研胜利。减少特征数量不必然减少雷达采集或特征提取成本：需明确哪些中间计算可复用、哪些计算可因删除特征而省略，以及真实时间/能耗预算。如果未来正式研究，应在新评价前确定允许的性能损失、成本指标与简单基线，保留此次事后提出假设的来源。

## 当前推进顺序

**现在执行 3A 数据谱系审计。** 当前没有可审计的 base-scene/group/env 报告。先确认哪些行是同一场景的增强副本，环境信息能否恢复、在实际选择特征时能否获得。这决定新验证方案和环境路线是否成立；不假设已有泄漏，也不伪造 group。

3A 后有两种需要重新立项的问题，而不是自动延续旧 PPO：

- 若目标是低成本特征选择：先量化真实特征成本，研究精度—成本折中，并把静态简单方法作为主对照。
- 若目标仍是 RL：需要真实的逐步决策，例如基于已观测特征选择下一项并决定何时停止。环境已知时一次选子集，应先比较简单条件化选择；3A 成功本身不证明必须用 RL。

若两种需求和数据条件都不存在，保留协议审计、奖励错配与动作支持诊断、静态搜索结果，将当前分支如实收尾，不为了得到正结果继续扩充模型。DFS 当前仍缺可追溯训练产物，不能宣称已超过或落后于合格的 DFS 复现。
