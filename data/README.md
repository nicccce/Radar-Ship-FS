# Data Directory

本目录用于放置项目本地数据，真实数据文件默认不提交到 Git。

建议结构：

- `raw/`：原始雷达舰船数据和只读备份；
- `processed/`：清洗、对齐、特征工程或切分后的可运行数据；
- `external/`：公开数据、上游示例数据或临时对照数据。

接入自有数据时请记录：数据来源、样本数、特征数、标签定义、预处理步骤、切分随机种子和生成时间。

## 雷达舰船 SVM-light 接入

实验代码内使用以下配置：

```python
load_config(
    {
        "dataset": "radar_ship",
        "data_dir": "../dataset",
        "validation_fraction": 0.25,
    }
)
```

加载器仅用源训练文件识别常数列和完全重复列，再把同一列掩码应用到源测试文件。
当前数据应得到训练文件 1843 行、测试文件 461 行、54 个有效特征；源测试文件由切分器
完整保留为最终测试分区。``validation_fraction=0.25`` 会把源训练文件划成约 60% 全体
样本的选择器训练集和约 20% 全体样本的奖励验证集。
